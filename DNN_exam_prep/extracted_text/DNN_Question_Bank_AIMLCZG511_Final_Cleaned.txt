Q1. A bank uses a single-layer neural network to classify loan applications based on income and credit
score. During testing, the classifier consistently misclassifies cases where the positive and negative
examples cannot be separated by a straight line. Analyze the reason for this behavior and explain what
architectural change would make the problem solvable.
Q2. A development team increases the number of epochs of a single-layer Perceptron because the
model is unable to correctly classify a particular dataset. Explain whether increasing training iterations
alone can overcome the limitation of the model.
Q3. Consider a neuron with x = [1, −2], w = [0.6, −0.4], and b = 0.2. Calculate the net input and output
using an appropriate activation function.
Q4. A classification system initially uses a Perceptron but later requires learning nonlinear decision
boundaries. Compare the role of the input, hidden and output layers in the redesigned network.
Q5. A company replaces a shallow network with a deeper network for image recognition. The training
accuracy improves significantly, but the engineers are unable to explain why. Explain how depth
enables hierarchical feature learning using a suitable example.
Q6. A medical-screening model performs well when the classes are linearly separable but fails when
several interacting features determine the class. Explain how adding hidden neurons can transform the
representation learned by the model.
Q7. A team argues that a sufficiently large number of neurons in a single-layer Perceptron should be
able to solve any binary classification problem. Evaluate this claim using a suitable decision-boundary
example.
Q8. A neural network uses Sigmoid activations in every hidden layer. As the network becomes deeper,
the gradients reaching the first hidden layer become extremely small. Explain the phenomenon and
recommend a more suitable activation strategy.
Q9. For a neuron with z = −2, calculate the output of Sigmoid, ReLU, and Leaky ReLU with α = 0.01.
Compare their behavior.
Q10. For z = 2, calculate the Sigmoid activation and its derivative. Explain what the derivative indicates
about gradient propagation.
Q11. A deep network uses Tanh activations in several hidden layers. The training process becomes
slow even though the loss decreases. Analyze whether Tanh could contribute to the problem.
Q12. A computer-vision model replaces Sigmoid hidden units with ReLU. The model trains faster, but
some neurons stop responding completely. Identify the possible problem and suggest a modification.
Q13. A regression model requires outputs that can take both positive and negative values. Compare
the suitability of ReLU, Sigmoid and Tanh for the output layer and justify a choice.
Q14. Two hidden-layer designs use ReLU and Leaky ReLU respectively. A developer reports that
some units in the ReLU network permanently output zero. Explain why this can happen and how the
alternative activation changes the behavior.
Q15. A predictive-maintenance network has two input neurons, two hidden Sigmoid neurons and one
Sigmoid output neuron. Given the input, weights and biases, perform complete forward propagation
