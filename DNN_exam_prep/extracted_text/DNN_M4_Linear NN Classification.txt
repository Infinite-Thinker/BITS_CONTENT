What is Classification?
Definition
Classiﬁcation is a supervised learning task that predicts a discrete category or
class label based on input features.
Key Characteristics:
Input: Feature vector x∈ Rd
Output: Class label y∈{ 1, 2,..., K} (discrete)
Goal: Learn a function f : Rd→{ 1, 2,..., K} that assigns inputs to classes
Difference from Regression:
Regression: Predicts continuous values (e.g., price, temperature)
Classiﬁcation: Predicts discrete categories (e.g., spam/not spam, cat/dog)

Properties of Sigmoid Function
Key Properties:
Range:σ(z)∈ (0, 1)→ perfect for probabilities!
Monotonic: Always increasing
Smooth: Differentiable everywhere
Symmetry: σ(−z) = 1−σ(z)
Derivative:σ′(z) = σ(z)(1−σ(z))
Behavior:
When z→ +∞:σ(z)→ 1 (conﬁdent class 1)
When z→−∞ :σ(z)→ 0 (conﬁdent class 0)
When z = 0:σ(z) = 0.5 (uncertain)
The derivative property makes sigmoid ideal for gradient-based learning!

Stochastic Gradient Descent (SGD)
Key Idea:
Instead of computing gradient over entire dataset, use gradient from a single ran-
dom example.
SGD Update Rule:
At iteration t:
1 Randomly select one example (x(i), y (i))
2 Compute gradient for this example:∇ℓ(w; x(i), y (i)) (noisy gradient estimate)
3 Update weights: w(t+1) = w(t)−η∇ℓ(w(t); x(i), y (i))
The noise in SGD actually helps escape local minima and often leads to better gen-
eralization!

Benefits and Challenges of SGD
Beneﬁts:
Speed: Much faster per iteration (only one example)
Memory: Can handle datasets that don’t ﬁt in memory
Online learning: Can update model as new data arrives
Generalization: Noise helps escape sharp minima
Scalability: Works well with massive datasets
Challenges:
Noisy updates: Path to minimum is not smooth
Learning rate: More sensitive toη choice
Convergence: May oscillate near minimum
Hyperparameter tuning: Requires careful tuning
Common compromise: Mini-batch SGD

Evaluating Classification Models
Unlike regression, we need different metrics for classiﬁcation.
Key Questions:
How often does the model predict correctly? (Accuracy)
What types of errors does it make? (Confusion Matrix)
How well does it identify positive cases? (Precision, Recall)
Data Split:
Training set: Learn weights w (typically 90-99%)
Validation set: Tune hyperparameters (typically 10-15%)
Test set: Final evaluation (typically 1-10%)
Always evaluate on unseen test data to measure generalization!

=== PAGE 42 ===
When to Use Which Metric?
Accuracy:
Use when classes are balanced
Misleading with imbalanced data! (e.g., 95% negative class)
Precision:
Important when False Positives are costly
Example: Spam detection (don’t want to mark real emails as spam)
Recall:
Important when False Negatives are costly
Example: Disease detection (don’t want to miss sick patients)
F1 Score:
Use when you need balance between precision and recall
Good for imbalanced datasets

Definition
Multi-class classiﬁcation assigns each input to one of K classes, where K > 2.
Key Characteristics:
Classes: y∈{ 1, 2, 3,..., K} (or{0, 1, 2,..., K− 1})
Each example belongs to exactly one class
Output: Probability distribution over all K classes
Probabilities sum to 1:
∑K

Example:
Input: Image of a handwritten digit
Output: Probabilities for each of 10 classes (0, 1, 2, ..., 9)
Prediction: Class with highest probability
