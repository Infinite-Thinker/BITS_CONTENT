Topic 1
Linear Systems, Gaussian Elimination & RREF
Reduce an augmented matrix, state the rank, decide whether there are no solutions, one solution or
infinitely many, and write the general solution — with and without a parameter in the system.
Formulas you need for this topic
• Augmented matrix [A | b]. Legal row operations: Ri ↔ Rj, Ri → cRi with c ̸= 0, Ri → Ri + cR j.
• rank = number of pivots in any echelon form = number of nonzero rows.
• rank A < rank[A | b]: no solution. rank A = rank[A | b] =n: exactly one. = r < n: infinitely many,
with n − r free variables.
• rank A + nullity A = n. General solution = particular solution + null-space part.
• A parameter inside A controls the rank; a parameter inside b controls consistency. Never divide by a
parameter without splitting into cases.

Vector Spaces, Subspaces, Linear Independence,
Basis & Dimension
Decide whether a set is a subspace, with a reason or a counter-example; test independence and find
the parameter value that makes vectors dependent; find a basis and the dimension of a span or of a
solution set, and extend a basis to the whole space.
Formulas you need for this topic
• Subspace test: 0 ∈ W, and W closed under addition and scalar multiplication (one failure is enough to
disprove).
• Independent ⇐ ⇒c1v1 + · · ·+ ckvk = 0 forces every ci = 0.
• n vectors in Rn: independent ⇐ ⇒det[v1 · · ·vn] ̸= 0.
• Basis = independent + spanning; dim W = number of basis vectors. In a d-dimensional space, d
independent vectors are automatically a basis.
• Basis of a span: row-reduce [v1 · · ·vk] and keep the original vectors sitting in pivot columns.
• Subspace given by equations: solve, then one basis vector per free variable; dim = n − rank.
Problem 7 · The plane x + y + z = 0
Show that W = {(x, y, z) ∈ R3 : x + y + z = 0} is a subspace of R3.
How to attempt this (the plan)
What it tests: the Subspace Test for a plane through the origin, given by one linear homogeneous
equation. Plan: check the zero vector; add two generic elements and regroup; scale a generic
element and factor out c.
Worked solution
STEP 1 zero 0 + 0 + 0 = 0, so (0, 0, 0) ∈ W. ✓
STEP 2 add Take (x1, y1, z1), (x2, y2, z2) ∈ W, so x1 + y1 + z1 = 0 and x2 + y2 + z2 = 0. The
sum is (x1 + x2, y1 + y2, z1 + z2) and
(x1 + x2) + (y1 + y2) + (z1 + z2) = (x1 + y1 + z1) + (x2 + y2 + z2) =0 + 0 = 0.
So the sum is in W. ✓
STEP 3 scale Take c ∈ R and (x, y, z) ∈ W. Then c(x, y, z) = (cx, cy, cz) and
cx + cy + cz = c(x + y + z) =c · 0 = 0.
So c(x, y, z) ∈ W. ✓
STEP 4 conclude All three tests pass, so W is a subspace of R3. Geometrically it is a plane
through the origin (with normal vector (1, 1, 1)).

Formulas you need for this topic
