(2) Consider the set of all n × n diagonalizable real matrices that have the
same eigenvectors and real eigenvalues. Does this set constitute a vector
space under standard operations of matrix addition and scalar multipli-
cation over the field of real numbers? If so, find the dimension of the
vector space, and a basis for it. Otherwise, show why it is not a vector
space. [5 Marks]
Solution: Each of the matrices in the set can be factorized in the form
of SΛS−1, where S is the common matrix of eigenvectors. Note that
such a decomposition exists since it is given that the matrices are all
diagonalizable. The given set is a subset of the set of all n × n matrices
which is a vector space since matrix addition and scalar mutliplication
satisfy all the vector space axioms. Therefore we can show that the given
set has all the properties of a vector space by showing that any linear
combination of two members of the set belong to the set: if A = SΛ1S−1
and B = SΛ2S−1 are in the set, then c1A + c2B is also in the set since
c1SΛ1S−1 +c2SΛ2S−1 = S(c1Λ1)S−1 +S(c2Λ2)S−1 = S(c1Λ1 +c2Λ2)S−1.
The dimension of this vector space is of dimension n, and a possible
basis is SF1S−1, SF2S−1, . . . SFnS−1, where Fi is a matrix where the
(i, i)th element is 1 and all other elements are 0. It can be easily seen
that these matrices are linearly independent and they span the entire
space as any element in the set can be expressed as a linear combination
of these basis vectors.
Suggested Marking Scheme: 3 Marks → showing that the given set
constitutes a vector space, 2 Marks → calculating the dimension of the
vector space and producing a basis.
