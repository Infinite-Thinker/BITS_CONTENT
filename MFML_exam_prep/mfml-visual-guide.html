Module 1

Solving linear systems

Before matrices mean anything, they are a bookkeeping trick for equations. This module builds that trick from the ground up and ends with a method that solves any system, every time.

1.1 What a system of equations is actually asking

Take two equations in two unknowns:

$$\begin{aligned} x + 2y &= 8\\ 3x - y &= 3 \end{aligned}$$

There are two completely different ways to picture this, and you need both. They will come back in every later topic.

The row picture: where do the lines cross?

Each equation is a line. A solution is a point sitting on both lines at once — so the answer is the intersection. Drag the coloured dots below to tilt the lines and watch the solution move.

The column picture: what mix of arrows lands on the target?

$$x\begin{bmatrix}1\\3\end{bmatrix}+y\begin{bmatrix}2\\-1\end{bmatrix}=\begin{bmatrix}8\\3\end{bmatrix}$$

Now the question changed shape. You have two arrows, and you're asked: how much of each do I need so that walking along them lands me exactly on the target arrow? Solving the system means finding the recipe.

1.2 Packing it into a matrix

Writing $x$ and $y$ over and over is wasted ink. The coefficients are the only thing that changes, so strip everything else away:

A = 123-1 ,   x = xy ,   b = 83   so   Ax = b

The rule for $A\mathbf{x}$: row $i$ of the answer is row $i$ of $A$ dotted with $\mathbf{x}$. Multiply across, add up, move down.

For the sizes to work, the number of columns in $A$ must equal the number of rows in $\mathbf{x}$. Write the shapes next to each other and cancel the inner pair:

$$\underbrace{(m\times \color{#4ec9e8}{n})}_{A}\;\underbrace{(\color{#4ec9e8}{n}\times p)}_{B}\;=\;(m\times p)$$

1.3 Gaussian elimination — the method that always works

Guessing works for 2×2. For anything bigger you need a procedure. Gaussian elimination is that procedure, and it rests on one fact: three moves change the equations but never change the solution.

  1. Swap two rows.
  2. Multiply a row by a non-zero number.
  3. Add a multiple of one row to another row.

Use them to chew the matrix down into a staircase — zeros below a leading entry in each row. That shape is called row echelon form, and the first non-zero in each row is a pivot. Once you have it, read the answer off from the bottom up.

The algorithm, compressed
  1. Go to the leftmost column that still has a non-zero below the staircase. If its top entry is 0, swap a row up.

  3. Move one row down and one column right. Repeat until you run out.
  4. Back-substitute from the bottom row upwards.

1.4 One solution, none, or infinitely many

Every linear system lands in exactly one of three buckets. In 2D with two equations you can literally see which:

Figure 1.4 — The only three things two lines can doclick a case

In echelon form you spot the bucket instantly:

What you see in the echelon formVerdict
A row like $[\,0\ 0\ 0 \mid 5\,]$ — zeros equalling something non-zeroNo solution. The system is inconsistent.
A pivot in every column of $A$, no contradiction rowExactly one solution.
Some column has no pivot (a free variable), no contradiction rowInfinitely many solutions.
When there are infinitely many, how do you write them all down?

Like this: general solution = one particular solution + everything that maps to zero.

$$\{\mathbf{x} : A\mathbf{x}=\mathbf{b}\} = \mathbf{x}_p + \underbrace{\{\mathbf{x} : A\mathbf{x}=\mathbf{0}\}}_{\text{null space / kernel}}$$

Read it as: get to the target once, then wander freely in any direction that $A$ flattens to nothing. You are still on target.

Module 2

Vector spaces

Module 1 gave you arrows and a target. This module asks the structural questions: which targets are reachable, how few arrows do you need, how long is an arrow, and what is the angle between two of them.

2.1 Linear independence

A linear combination of vectors is any weighted sum: $\lambda_1\mathbf{v}_1 + \lambda_2\mathbf{v}_2 + \dots$. The set of everything you can reach that way is the span.

Now the definition that gets examined. Vectors $\mathbf{v}_1,\dots,\mathbf{v}_k$ are linearly independent if

$$\lambda_1\mathbf{v}_1+\dots+\lambda_k\mathbf{v}_k=\mathbf{0} \quad\text{forces}\quad \lambda_1=\dots=\lambda_k=0$$

In English: the only way to cancel them out to nothing is to use none of them. If any other combination reaches zero, they are dependent — and dependent means one of them was redundant, expressible from the others.

2.2 Basis and rank

A basis is the Goldilocks set: enough vectors to span the whole space, but not one more than necessary.

PropertyMeaning
SpanningEvery vector in the space is reachable as a combination. Enough arrows.
IndependentNone of them is redundant. Not too many arrows.
BasisBoth at once. Every vector has exactly one recipe.

The number of vectors in a basis is the dimension. Every basis of the same space has the same size — that's a theorem worth quoting.

Rank

The rank of a matrix is the number of pivots after elimination. Equivalently: the number of genuinely independent columns. The surprise result you should be able to state:

$$\text{rk}(A)=\dim(\text{column space})=\dim(\text{row space})=\text{rk}(A^{\!\top})$$

Row rank equals column rank. Always. Even for a 2×900 matrix.

Figure 2.2 — Rank is how much dimension survivespick a matrix and watch the grid flatten
The rank–nullity theorem

For $A \in \mathbb{R}^{m\times n}$:

$$\underbrace{\text{rk}(A)}_{\text{dimensions that survive}}+\underbrace{\dim(\ker A)}_{\text{dimensions crushed to }\mathbf 0}=\underbrace{n}_{\text{columns you started with}}$$

Nothing vanishes without being accounted for. If $A$ is 3×3 with rank 2, the kernel is $3-2=1$ dimensional — a line of vectors gets sent to zero.

2.3 Affine spaces

A subspace must contain the origin — that's forced, because $0\cdot\mathbf{v}=\mathbf{0}$ must stay inside. So a line through the origin is a subspace; a line that misses the origin is not.

An affine subspace is a subspace that has been picked up and moved:

$$L = \mathbf{x}_0 + U = \{\mathbf{x}_0 + \mathbf{u} : \mathbf{u}\in U\}$$

with $\mathbf{x}_0$ the support point and $U$ the direction space. You already built one of these in §1.4 — the solution set $\mathbf{x}_p + \ker(A)$ is exactly this shape.

2.4 Norms — how long is a vector?

A norm $\|\cdot\|$ assigns a length to each vector. Any sensible notion of length obeys three rules, and these are quotable definitions:

  • Absolutely homogeneous: $\|\lambda\mathbf{x}\|=|\lambda|\,\|\mathbf{x}\|$ — double the vector, double the length.
  • Triangle inequality: $\|\mathbf{x}+\mathbf{y}\|\le\|\mathbf{x}\|+\|\mathbf{y}\|$ — detours are never shorter.
  • Positive definite: $\|\mathbf{x}\|\ge0$, and $=0$ only for $\mathbf{x}=\mathbf{0}$.

Different rules for "length" give different norms. The three you need:

2.5 Inner products, lengths and distances

The dot product is the familiar one:

$$\langle \mathbf{x},\mathbf{y}\rangle = \mathbf{x}^{\!\top}\mathbf{y}=\sum_{i=1}^n x_iy_i$$

A general inner product is any function of two vectors that is bilinear (linear in each slot), symmetric ($\langle\mathbf x,\mathbf y\rangle=\langle\mathbf y,\mathbf x\rangle$) and positive definite ($\langle\mathbf x,\mathbf x\rangle>0$ for $\mathbf x\neq\mathbf 0$). It can be written with a symmetric positive-definite matrix $A$:

$$\langle \mathbf{x},\mathbf{y}\rangle = \mathbf{x}^{\!\top}A\,\mathbf{y}$$

Take $A=I$ and you're back to the dot product. Any other $A$ stretches space before measuring — a different ruler.

Everything else is built on top:

  • Length: $\|\mathbf x\| = \sqrt{\langle\mathbf x,\mathbf x\rangle}$
  • Distance: $d(\mathbf x,\mathbf y)=\|\mathbf x-\mathbf y\|$
  • Angle: next section

2.6 Angles and orthogonality

The Cauchy–Schwarz inequality says $|\langle\mathbf x,\mathbf y\rangle|\le\|\mathbf x\|\|\mathbf y\|$, so the ratio below always lands in $[-1,1]$ — which means it is legally a cosine:

$$\cos\omega=\frac{\langle\mathbf x,\mathbf y\rangle}{\|\mathbf x\|\,\|\mathbf y\|}$$

Two vectors are orthogonal, written $\mathbf x\perp\mathbf y$, when $\langle\mathbf x,\mathbf y\rangle=0$. That's a 90° angle. If they are also both unit length, they are orthonormal.

Orthogonal matrices

A square matrix $A$ is orthogonal when its columns are orthonormal. The consequence is the useful bit:

$$AA^{\!\top}=I=A^{\!\top}A \quad\Longrightarrow\quad A^{-1}=A^{\!\top}$$

Inverting becomes free — just transpose. And orthogonal matrices preserve lengths and angles: they are exactly the rotations and reflections. Nothing gets stretched.

2.7 Orthonormal basis and Gram–Schmidt

An orthonormal basis is a basis where every vector has length 1 and every pair is perpendicular:

$$\langle \mathbf b_i,\mathbf b_j\rangle = 0 \;(i\neq j),\qquad \|\mathbf b_i\|=1$$

Why bother? Because finding coordinates stops being work. In a general basis you must solve a linear system to find the recipe for $\mathbf x$. In an orthonormal basis you just take dot products:

$$\mathbf x = \langle\mathbf x,\mathbf b_1\rangle\,\mathbf b_1+\langle\mathbf x,\mathbf b_2\rangle\,\mathbf b_2+\dots$$

Gram–Schmidt is the machine that turns any basis into an orthonormal one. The idea in one line: take the next vector, subtract off the part that points along what you already have, then normalise what's left.

Module 3

Matrix decomposition

A matrix is a transformation of space. This module takes that transformation apart into simple, understandable pieces — a rotation here, a stretch there — and then throws the small pieces away to compress data.

3.1 Determinant and trace

The determinant answers one question: by what factor does this matrix scale area (2D) or volume (3D)? A negative determinant means space got flipped over as well.

The formulas you must have memorised:

$$\det\begin{bmatrix}a&b\\c&d\end{bmatrix}=ad-bc$$ $$\det\begin{bmatrix}a&b&c\\d&e&f\\g&h&i\end{bmatrix}=a(ei-fh)-b(di-fg)+c(dh-eg)$$

That second one is Laplace expansion along the first row: walk across the row, and for each entry multiply it by the determinant of the 2×2 you get when you delete its row and column. The signs alternate $+,-,+$.

Trace

The trace is embarrassingly simple — add the diagonal:

$$\text{tr}(A)=\sum_{i=1}^n a_{ii}$$

Its one magic property: $\text{tr}(AB)=\text{tr}(BA)$, which lets you cycle factors around, $\text{tr}(ABC)=\text{tr}(CAB)$. That's why trace survives a change of basis and appears everywhere in machine learning derivations.

3.3 Eigendecomposition and diagonalization

If a matrix has $n$ independent eigenvectors, stack them as the columns of $P$ and put the eigenvalues on the diagonal of $D$. Then

$$A = PDP^{-1}\qquad\Longleftrightarrow\qquad P^{-1}AP = D$$

Read right to left as a three-act story. $P^{-1}$ rewrites your vector in eigen-coordinates. $D$ stretches each axis independently — trivially easy. $P$ translates back to normal coordinates.

The payoff is powers. $A^k = PD^kP^{-1}$, and raising a diagonal matrix to a power just means raising each diagonal entry. A hundred matrix multiplications becomes two.

3.4 Cholesky decomposition

$$A = LL^{\!\top}$$

3.5 Singular value decomposition

Eigendecomposition needs a square, diagonalizable matrix. SVD needs nothing — every matrix, any shape, has one:

$$A = U\Sigma V^{\!\top}$$

$U$ ($m\times m$) and $V$ ($n\times n$) are orthogonal; $\Sigma$ ($m\times n$) is diagonal with non-negative entries $\sigma_1\ge\sigma_2\ge\dots\ge0$, the singular values.

Geometrically every matrix does the same three things in order: rotate, stretch along axes, rotate again. That's it. A unit circle can only ever become an ellipse.

3.6 Matrix approximation

Split the SVD into a sum of rank-1 pieces:

$$A=\sum_{i=1}^{r}\sigma_i\,\mathbf u_i\mathbf v_i^{\!\top}$$

Each piece is weighted by its singular value, and they are sorted largest first. So keep the first $k$ and throw the rest away:

$$\hat A_k=\sum_{i=1}^{k}\sigma_i\,\mathbf u_i\mathbf v_i^{\!\top}$$

The Eckart–Young theorem says this is not just a good rank-$k$ approximation — it is the best possible one, and the error it leaves is exactly the largest discarded singular value:

$$\min_{\text{rk}(B)=k}\|A-B\|_2=\|A-\hat A_k\|_2=\sigma_{k+1}$$

This is image compression, PCA, recommender systems and topic modelling — all the same trick. Slide the rank below and watch the picture come back.

4.2 Taylor series

A Taylor series rebuilds a function out of polynomials, using only derivative information at a single point $a$:

$$f(x)=\sum_{k=0}^{\infty}\frac{f^{(k)}(a)}{k!}(x-a)^k$$ $$=f(a)+f'(a)(x-a)+\frac{f''(a)}{2!}(x-a)^2+\frac{f'''(a)}{3!}(x-a)^3+\dots$$

Cut it off after $n$ terms and you have the Taylor polynomial $T_n$. When $a=0$ it gets the name Maclaurin series.

The intuition: term 0 matches the height, term 1 matches the slope, term 2 matches the curvature, and each extra term matches one more derivative. Add terms below and watch the polynomial grip the curve further and further out.

4.3 Partial derivatives and gradients

With several inputs, "the slope" isn't a single number — it depends which way you walk. A partial derivative fixes all variables but one:

$$\frac{\partial f}{\partial x_1}=\lim_{h\to0}\frac{f(x_1+h,x_2)-f(x_1,x_2)}{h}$$

Practically: differentiate with respect to one variable and treat the others as constants. That's the entire technique.

Collect all the partials into one vector and you have the gradient:

$$\nabla f=\begin{bmatrix}\partial f/\partial x_1\\ \vdots \\ \partial f/\partial x_n\end{bmatrix}$$

Two facts to memorise and never mix up:

  • The gradient points in the direction of steepest increase. Gradient descent therefore steps along $-\nabla f$.
  • The gradient is always perpendicular to the contour line through that point.

4.4 Gradients of vector-valued functions — the Jacobian

Now the output is a vector too: $\mathbf f:\mathbb{R}^n\to\mathbb{R}^m$. Each output component has its own gradient, so stack them as rows. The result is the Jacobian, an $m\times n$ matrix:

$$J=\frac{d\mathbf f}{d\mathbf x}=\begin{bmatrix} \frac{\partial f_1}{\partial x_1}&\cdots&\frac{\partial f_1}{\partial x_n}\\ \vdots&\ddots&\vdots\\ \frac{\partial f_m}{\partial x_1}&\cdots&\frac{\partial f_m}{\partial x_n}\end{bmatrix}$$

Row $i$, column $j$ = how much output $i$ changes when input $j$ wiggles. Getting the shape right is worth marks on its own: rows count outputs, columns count inputs.

The Jacobian is the best linear approximation of $\mathbf f$ near a point, and $|\det J|$ is the local volume-scaling factor — which is exactly why it appears in the change-of-variables formula for probability densities.

Worked example — the least-squares gradient6 steps
1

Minimise $L(\boldsymbol\theta)=\|\mathbf y-X\boldsymbol\theta\|^2$. This is linear regression, and the derivation is a stock exam question.

2

Expand the squared norm as an inner product:

$$L=(\mathbf y-X\boldsymbol\theta)^{\!\top}(\mathbf y-X\boldsymbol\theta)$$ $$=\mathbf y^{\!\top}\mathbf y-2\boldsymbol\theta^{\!\top}X^{\!\top}\mathbf y+\boldsymbol\theta^{\!\top}X^{\!\top}X\boldsymbol\theta$$

The two cross terms are equal because each is a scalar, and a scalar equals its own transpose.

3

Differentiate term by term. The first has no $\boldsymbol\theta$, so it dies.

Second term, using $\partial(\mathbf a^{\!\top}\boldsymbol\theta)/\partial\boldsymbol\theta=\mathbf a^{\!\top}$:   $-2\mathbf y^{\!\top}X$

4

Third term, using $\partial(\boldsymbol\theta^{\!\top}B\boldsymbol\theta)/\partial\boldsymbol\theta=2\boldsymbol\theta^{\!\top}B$ with the symmetric $B=X^{\!\top}X$:

$2\boldsymbol\theta^{\!\top}X^{\!\top}X$

Together: $\dfrac{\partial L}{\partial\boldsymbol\theta}=-2\mathbf y^{\!\top}X+2\boldsymbol\theta^{\!\top}X^{\!\top}X$

5

Set to zero and transpose into column form:

$$X^{\!\top}X\boldsymbol\theta=X^{\!\top}\mathbf y$$

These are the normal equations. Note they are just a linear system — Module 1 solves them.

6

If $X^{\!\top}X$ is invertible:

$$\boxed{\boldsymbol\theta=(X^{\!\top}X)^{-1}X^{\!\top}\mathbf y}$$

Every module so far, in one formula: a linear system, an inner product, an inverse, and a gradient set to zero.

4.6 Backpropagation and automatic differentiation

Write a complicated function as a chain of simple operations. Give every intermediate result a name. Now you have a computation graph, and the chain rule applies to it mechanically.

Forward pass: walk left to right, computing values.
Backward pass: walk right to left, multiplying local derivatives.

That's automatic differentiation. Backpropagation is the name it goes by when the graph is a neural network. Nothing more mysterious than that.

Figure 4.4 — Forward then backward through a graphf = (a + b) · c
Why backward and not forward?

Both directions compute correct derivatives. The difference is cost.

  • Forward mode costs one sweep per input. Good when you have few inputs and many outputs.
  • Reverse mode costs one sweep per output. Good when you have many inputs and one output.

A neural network has millions of parameters and exactly one loss. Reverse mode wins by a factor of millions. That asymmetry is the entire reason deep learning is computationally possible.

Worked example — backprop through one neuron8 steps
1

One neuron with a sigmoid and a squared loss:

$$z=wx+b,\qquad a=\sigma(z)=\frac{1}{1+e^{-z}},\qquad L=(a-y)^2$$

Inputs: $x=1$, $w=0.5$, $b=0$, target $y=1$. Find $\partial L/\partial w$ and $\partial L/\partial b$.

2

Forward pass. $z=0.5(1)+0=0.5$

3

$a=\sigma(0.5)=\dfrac{1}{1+e^{-0.5}}=\dfrac{1}{1+0.6065}=0.6225$

4

$L=(0.6225-1)^2=(-0.3775)^2=0.1425$

Forward pass done. Store $z$ and $a$ — the backward pass needs them.

5

Backward pass. Start at the loss.

$\dfrac{\partial L}{\partial a}=2(a-y)=2(-0.3775)=-0.7551$

6

The sigmoid has a famously tidy derivative, $\sigma'(z)=\sigma(z)\big(1-\sigma(z)\big)=a(1-a)$:

$\dfrac{\partial a}{\partial z}=0.6225(1-0.6225)=0.6225(0.3775)=0.2350$

Chain them: $\dfrac{\partial L}{\partial z}=-0.7551\times0.2350=-0.1774$

7

Last hop. From $z=wx+b$: $\partial z/\partial w=x=1$ and $\partial z/\partial b=1$.

$\dfrac{\partial L}{\partial w}=-0.1774\times1=\boxed{-0.1774}$

$\dfrac{\partial L}{\partial b}=-0.1774\times1=\boxed{-0.1774}$

8

Take one gradient-descent step with $\eta=0.1$:

$w\leftarrow0.5-0.1(-0.1774)=0.5177$

The gradient is negative, so $w$ increases, pushing $a$ up towards the target $y=1$. Sanity confirmed.

Your turn

For $f(x)=\sqrt{x^2+e^{x^2}}$ at $x=1$, build the graph and backpropagate.

Show solution

Graph: $u=x^2$, $v=e^{u}$, $s=u+v$, $f=\sqrt{s}$.

Forward: $u=1$, $v=e\approx2.718$, $s=3.718$, $f=1.928$.

Backward: $\frac{\partial f}{\partial s}=\frac{1}{2\sqrt s}=0.2593$;   $\frac{\partial s}{\partial u}=1+e=3.718$ (both paths $u\to s$ and $u\to v\to s$ — add them);   $\frac{\partial u}{\partial x}=2x=2$.

The key habit: when a node feeds two later nodes, sum the gradients arriving back along both paths.

4.7 The Hessian

The gradient holds first derivatives. Differentiate again and collect all second partials into a square matrix — the Hessian:

$$H=\nabla^2f=\begin{bmatrix} \frac{\partial^2f}{\partial x^2} & \frac{\partial^2f}{\partial x\,\partial y}\\[4pt] \frac{\partial^2f}{\partial y\,\partial x} & \frac{\partial^2f}{\partial y^2}\end{bmatrix}$$

If the second partials are continuous, mixed partials commute ($f_{xy}=f_{yx}$ — Schwarz's theorem), so the Hessian is symmetric. That means it has real eigenvalues and an orthogonal eigenbasis — Module 3 comes back to help.

The gradient tells you a point is flat. The Hessian tells you what kind of flat: a bowl, a dome, or a saddle.

Second-order Taylor, the multivariate version

The Hessian is the $k=2$ term of a Taylor expansion in several variables:

$$f(\mathbf x)\approx f(\mathbf a)+\nabla f(\mathbf a)^{\!\top}(\mathbf x-\mathbf a)+\tfrac12(\mathbf x-\mathbf a)^{\!\top}H(\mathbf a)(\mathbf x-\mathbf a)$$

Compare it term by term with the single-variable version and the pattern is exact: value, then slope times displacement, then half curvature times displacement squared.

Worked example — classify every critical point8 steps
1

$f(x,y)=x^3-3xy+y^3$. Find and classify all critical points.

2

First derivatives:

$f_x=3x^2-3y$,   $f_y=-3x+3y^2$

3

Set both to zero. From $f_x=0$: $y=x^2$. Substitute into $f_y=0$:

$-3x+3(x^2)^2=0 \Rightarrow x^4-x=0 \Rightarrow x(x^3-1)=0$

So $x=0$ or $x=1$, giving critical points $(0,0)$ and $(1,1)$.

4

Second derivatives:

$f_{xx}=6x$,   $f_{yy}=6y$,   $f_{xy}=f_{yx}=-3$

H = 6x-3-36y

Symmetric, as promised.

5

At $(0,0)$:

0-3-30

$\det H=0-9=-9<0$  ⟹  saddle point.

Eigenvalues are $+3$ and $-3$ — up one way, down the other.

6

At $(1,1)$:

6-3-36

$\det H=36-9=27>0$ and $f_{xx}=6>0$  ⟹  local minimum.

7

$(6-\lambda)^2-9=0 \Rightarrow 6-\lambda=\pm3 \Rightarrow \lambda=3,9$

Both positive → positive definite → minimum ✓

8

Second-order Taylor around that minimum. Since $\nabla f(1,1)=\mathbf 0$ and $f(1,1)=1-3+1=-1$:

$$f\approx-1+\tfrac12\big[6(x{-}1)^2-6(x{-}1)(y{-}1)+6(y{-}1)^2\big]$$ $$=-1+3(x{-}1)^2-3(x{-}1)(y{-}1)+3(y{-}1)^2$$

The $-6$ cross term comes from both off-diagonal entries of $H$, each $-3$.

Before the exam

Mixed drills

No topic labels on these — just like the paper. Work out which tool applies before you start calculating. That identification step is half the exam.

Drill 1

For which value of $k$ does the system $x+2y=3$, $2x+ky=6$ have infinitely many solutions?

Show solution

$R_2\leftarrow R_2-2R_1$ gives $\big[\,0\ \ k-4\ \big|\ 0\,\big]$.

If $k\neq4$ you get a pivot in column 2 → unique solution. If $k=4$ the row is all zeros → $y$ is free → infinitely many solutions.

There is no $k$ giving no solution here, because the right-hand side happens to cancel to 0 as well. Worth noticing — examiners like that trap.

Drill 2

Find the angle between $\mathbf x=(1,0,1)$ and $\mathbf y=(1,1,0)$.

Show solution

$\langle\mathbf x,\mathbf y\rangle=1+0+0=1$;   $\|\mathbf x\|=\|\mathbf y\|=\sqrt2$

$\cos\omega=\frac{1}{2}$  ⟹  $\omega=60^\circ$

Drill 3

$A$ is 3×3 with eigenvalues $2, -1, 4$. Without computing anything else, state $\det A$, $\text{tr}(A)$, and whether $A$ is invertible.

Show solution

$\det A=2\times(-1)\times4=\mathbf{-8}$

$\text{tr}(A)=2-1+4=\mathbf{5}$

Invertible, because no eigenvalue is zero (equivalently $\det\neq0$).

Bonus: eigenvalues of $A^{-1}$ are $\tfrac12,-1,\tfrac14$, and of $A^2$ are $4,1,16$.

Drill 4

Is $A=\begin{bmatrix}2&-1\\-1&2\end{bmatrix}$ positive definite? If so, give its Cholesky factor.

Show solution

Symmetric ✓. Eigenvalues: $(2-\lambda)^2-1=0 \Rightarrow \lambda=1,3$, both positive → positive definite.

$l_{11}=\sqrt2$;  $l_{21}=-1/\sqrt2$;  $l_{22}=\sqrt{2-\tfrac12}=\sqrt{1.5}$

$L=\begin{bmatrix}1.414&0\\-0.707&1.225\end{bmatrix}$

Check $\det A=(\det L)^2$: $(1.414\times1.225)^2=(1.732)^2=3$, and $4-1=3$ ✓

Drill 5

Compute $\nabla f$ and $H$ for $f(\mathbf x)=\mathbf x^{\!\top}A\mathbf x$ where $A=\begin{bmatrix}3&1\\1&2\end{bmatrix}$.

Show solution

$A$ is symmetric, so $\nabla f=2A\mathbf x=\begin{bmatrix}6x_1+2x_2\\2x_1+4x_2\end{bmatrix}$.

Differentiating again: $H=2A=\begin{bmatrix}6&2\\2&4\end{bmatrix}$ — constant, because $f$ is a pure quadratic.

Longhand check: $f=3x_1^2+2x_1x_2+2x_2^2$, so $f_{x_1}=6x_1+2x_2$ ✓, $f_{x_1x_1}=6$ ✓, $f_{x_1x_2}=2$ ✓

Drill 6

A 4×6 matrix has rank 3. Give the dimension of its kernel, its column space, and its row space.

Show solution

$n=6$ columns. Rank–nullity: $3+\dim\ker=6$ → $\dim\ker=3$.

Column space: 3 (a 3-dimensional subspace of $\mathbb R^4$).

Row space: 3 (a 3-dimensional subspace of $\mathbb R^6$). Row rank always equals column rank.

Drill 7

Find the first three non-zero terms of the Maclaurin series for $f(x)=e^{-x^2}$.

Show solution

Don't differentiate four times — substitute. Start from $e^u=1+u+\tfrac{u^2}{2}+\dots$ and set $u=-x^2$:

$e^{-x^2}=1-x^2+\tfrac{x^4}{2}-\dots$

Substituting into a known series is almost always faster and is fully rigorous.

Drill 8

The singular values of a 3×3 matrix are $\sigma=10, 4, 0.5$. What is the smallest possible error, in the spectral norm, from a rank-2 approximation?

Show solution

Eckart–Young: the error equals the first discarded singular value, $\sigma_{k+1}$ with $k=2$.

Error $=\sigma_3=0.5$

Since $\sigma_3$ is tiny compared with $\sigma_1$, this matrix is very nearly rank 2 — exactly the situation where compression pays off.

Drill 9

Show that if $Q$ is orthogonal then $\|Q\mathbf x\|=\|\mathbf x\|$.

Show solution

$\|Q\mathbf x\|^2=(Q\mathbf x)^{\!\top}(Q\mathbf x)=\mathbf x^{\!\top}Q^{\!\top}Q\mathbf x$

But $Q^{\!\top}Q=I$, so this is $\mathbf x^{\!\top}\mathbf x=\|\mathbf x\|^2$. Take square roots. $\blacksquare$

This is why $U$ and $V$ in the SVD contribute no stretching — all the scaling lives in $\Sigma$.

Drill 10

Using backpropagation, find $\frac{df}{dx}$ for $f=\sin(x^2)\cdot e^{x}$ at $x=0$.

Show solution

Graph: $u=x^2$, $p=\sin u$, $q=e^x$, $f=pq$.

Forward at $x=0$: $u=0$, $p=0$, $q=1$, $f=0$.

Backward: $\partial f/\partial p=q=1$, $\partial f/\partial q=p=0$.

Path through $p$: $1\times\cos(0)\times2(0)=0$.   Path through $q$: $0\times e^0=0$.

$f'(0)=0+0=0$

Direct check: $f'=2x\cos(x^2)e^x+\sin(x^2)e^x$, and both terms vanish at 0 ✓
